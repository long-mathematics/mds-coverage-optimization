# MDS coverage optimization

Research manuscripts by **Christopher D. Long** on active-uniform Gamma/MDS allocation and the expected terminal-cloud support staircase.

This repository is being initialized through a feature branch and pull request. Its active scope is deliberately limited to these two related allocation problems. Motif-channel inference, capacity, and decoding are not part of the active paper collection.
